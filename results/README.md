# Results Directory

This directory contains compact public artifacts used by the manuscript and figure scripts.

- `tables/`: headline cross-domain tables, non-medical sanity summaries, CUPS summary, and MATH-500 capability gradient.
- `source_tables/`: compact paired source tables used for rescue/harm figures.
- `figures/`: final PNG/PDF figures and regenerated outputs from `scripts/figures/generate_academic_figures.py`.
- `cups/`: CUPS policy sweeps, paired tests, strategy mixes, and missing-scope notes.
- `mechanism/`: rescue/harm and oracle-opportunity diagnostics.
- `robustness/`: MATH-500 robustness and frontier-model summary tables.
- `ci/`: bootstrap confidence-interval tables.

Full per-item predictions and raw provider logs are intentionally excluded from this GitHub release.
